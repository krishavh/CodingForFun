Thermal Lab

Real-time temperature monitoring using ESP32 boards, MQTT, SQLite, and a simple browser dashboard. It works for server cooling, room tests, freezer checks, plant experiments, or any project where temperature changes matter.

How It Works

  1. An ESP32 reads a temperature value from its board or from a connected sensor.
  2. The ESP32 sends a small JSON message over Wi-Fi using MQTT.
  3. The Python server listens to MQTT and stores each reading in SQLite.
  4. Your browser asks the server for the newest data and draws cards, a chart, and a table.
[ESP32 probe] --Wi-Fi--> [MQTT broker] --> [Python server] --> [SQLite] --> [Browser]

What Is an ESP32?

An ESP32 is a tiny computer with built-in Wi-Fi. You can program it once, power it with USB, and let it send sensor readings every few seconds. In this project, it acts like a wireless thermometer.

What Is MQTT?

MQTT is a lightweight message system. Think of it like a shared bulletin board. The ESP32 posts a reading to a topic, and the dashboard subscribes to that topic to read it.

Message Format

Send JSON to a topic like esp32/desk-outlet/telemetry. Any key ending in _c is treated as Celsius.

{
  "device": "desk-outlet",
  "ambient_c": 24.8,
  "outlet_c": 33.4,
  "rssi": -54
}

Cooling Safety

Keep water away from electronics. Do not open power supplies. Do not disable thermal shutdown. If a CPU, GPU, or case reading climbs above your safe limit, stop the test and check airflow before continuing.
