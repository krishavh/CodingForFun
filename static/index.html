Use This With Any ESP32

An ESP32 is a tiny Wi-Fi computer. Put one near the air going into a machine, another near the hot air coming out, and this page turns the readings into a live cooling story.

  1. Flash each ESP32 with a unique device name like rack-inlet or desk-outlet.
  2. Send MQTT messages to the broker using the topic esp32/<device-id>/telemetry.
  3. Publish temperatures in Celsius. The dashboard can show Celsius or Fahrenheit.
  4. Move fans, vents, or probe locations, then watch whether the graph rises or falls.

Example MQTT Payload

Topic:
esp32/desk-outlet/telemetry

Payload:
{
  "device": "desk-outlet",
  "ambient_c": 24.8,
  "outlet_c": 33.4,
  "rssi": -54
}

Names ending in _c are saved as Celsius readings, so you can add sensors like case_c, inlet_c, or probe_c.
